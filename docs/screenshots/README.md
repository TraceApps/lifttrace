# Screenshots

These are the canonical screenshots embedded by the project README and
linked from release pages. Numbered prefix is the display order, so
inserting or removing entries should preserve the gap pattern instead
of renumbering — that way external links (release notes, social posts)
don't break when a single shot is refreshed.
